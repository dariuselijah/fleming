# Licensing outreach pack

Use these templates to open commercial conversations. Replace bracketed fields before sending.

## 1. MediKredit — NAPPI Product & Price File

**To:** nappi@medikredit.co.za (confirm current commercial contact)  
**Subject:** Commercial subscription — NAPPI Product & Price File for API redistribution

We are building a South African healthcare reference-data API (schemes, tariffs, products, ICD-10) for practice-management and EHR vendors. We require a quotation for:

1. Public-domain NAPPI file access confirmation and permitted API republication of code / description / strength / pack / manufacturer.
2. Product & Price File subscription covering pharmaceuticals and surgical / consumables (including 0201-class items), with **redistribution rights** into a multi-tenant commercial API (not end-user desktop only).
3. Update cadence, file formats, and trademark usage guidelines for displaying NAPPI codes (not the NAPPI brand as our product name).

Fleming Health / [Company] will be the first customer. Please advise commercial packs and NDA process.

## 2. Alternate NAPPI list vendor

**Subject:** NAPPI product list — redistribution for commercial API

Please confirm whether your NAPPI product list licence permits:

- Serving codes and descriptions via a multi-tenant REST API to third-party software vendors.
- Joining your list to NDoH Single Exit Price (SEP) data for medicine pricing.
- Daily / weekly refresh of the catalogue.

If redistribution is restricted to internal use only, we cannot proceed without an expanded commercial schedule.

## 3. SAMA — eMDCM / CCSA commercial redistribution

**To:** SAMA eStore / coding licensing contact  
**Subject:** Commercial redistribution licence — procedure coding for Tariff Rates API

We need a commercial licence to include SAMA Medical Doctors’ Coding Manual (eMDCM) and/or Complete CPT for South Africa (CCSA) **code + description** fields inside a paid Tariff Rates API used by PMS/EHR vendors. Ordinary user licences appear limited to internal use; please advise the commercial / AMA-aligned redistribution path, annual fees, and attribution requirements.

## 4. NDoH — MIT and SEP republication

**Subject:** Confirmation of commercial API packaging — ICD-10 MIT and Database of Medicine Prices (SEP)

We will ingest:

- ICD-10 Master Industry Table (current official MIT + emergency COVID codes)
- Database of Medicine Prices / SEP schedules published under NHI / PEE materials

Please confirm attribution wording and any restrictions on offering search/validate APIs over these public files (without claiming official NDoH endorsement).

## 5. Scheme tariff redistribution (GEMS example)

**Subject:** Permission to normalise and redistribute 2026 provider tariff files via commercial API

We collect publicly posted provider tariff Excel/PDF files for lookup by software vendors (code, discipline, network flag, rand amount, effective year). Please confirm whether [Scheme] permits:

1. Machine-readable redistribution of tariff amounts published for healthcare providers.
2. Display of scheme name + option context in third-party billing software.

We will retain provenance (`source_file_id`, ingest date) on every row.
